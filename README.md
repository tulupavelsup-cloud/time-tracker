# Тайм-трекер

Мобильный тайм-трекер (таргет 390×844): категории и задачи, сессии по таймеру,
статистика за день/неделю/месяц с графиками — и мини-планета, где у каждой
категории свой «бизнес» (шахта, корпорация, космопорт, нефтевышка, банк),
растущий по мере наработанных часов. Визуал — глассморфизм поверх живой
зелёной сцены, шрифты Unbounded + Golos Text.

Стек: Vite + React + TypeScript + Tailwind CSS + Framer Motion + Supabase
(auth и данные, доступ только через обёртки в `src/api/`).

## Быстрый старт

```bash
npm i
# ключи Supabase в .env — по шагам из SETUP.md
npm run dev
```

Открыть http://127.0.0.1:5173 (основной таргет вёрстки — 390×844).

## Демо-режим без БД

Добавьте `?demo=1` к адресу — приложение работает на встроенных демо-данных,
Supabase и `.env` не нужны:

```
http://127.0.0.1:5173/?demo=1
```

Полезные параметры поверх демо: `&tab=planet` (сразу экран планеты),
`&zone=<тема>` (сразу интерьер зоны).

## ⚠️ Письма из трекера: разрешить адрес прода

Ссылки в письмах Supabase — подтверждение почты при регистрации и
восстановление пароля — ведут **не туда, куда просит приложение**, а на Site URL
проекта. Сейчас это `http://localhost:3000`: адрес прода в списке разрешённых
отсутствует, и человек по такой ссылке попадает в никуда.

Лечится один раз в панели Supabase → **Authentication → URL Configuration →
Redirect URLs**, добавить:

    https://time-tracker-7ux.pages.dev/**

Site URL при этом трогать не нужно — он общий с другим проектом. Проверить
можно так: попросить письмо «забыли пароль» и посмотреть, куда ведёт ссылка.
