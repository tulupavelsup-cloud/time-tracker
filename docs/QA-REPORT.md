## Дефекты — все исправлены (коммит `d5afddc`, перепроверено 2026-07-20)

**Д-1 (критично, зона frontend-ui): тап по зоне планеты не открывает интерьер.** ИСПРАВЛЕНО: capture после порога 6px в `onPointerMove`; перепроверено реальным кликом (мышь) — интерьер открывается, драг не открывает.
Место: `src/screens/Planet.tsx:152` — в `onPointerDown` контейнера вращения вызывается `e.currentTarget.setPointerCapture(e.pointerId)`. Pointer capture переводит `pointerup` на контейнер, поэтому итоговый `click` диспатчится в контейнер, а не в кнопку зоны — `onClick` кнопки (`Planet.tsx:259`, `setOpened(z.cat)`) не срабатывает.
Доказательство (Playwright, реальный клик мышью по кнопке «Зона „Саморазвитие“ — открыть»): интерьер не открылся; программный `el.click()` тут же открыл. На телефоне тап по зоне работать не будет — ключевой сценарий ТЗ «тап по зоне ныряет внутрь» сломан.
Рекомендация: не захватывать pointer на `pointerdown`, а ставить capture только после порога перемещения (например, |dx| больше 6px) в `onPointerMove`, либо не вызывать `setPointerCapture` вовсе.

**Д-2 (минор): нет `npm run lint`.** ИСПРАВЛЕНО: ESLint flat-конфиг + скрипт `lint`, прогон чистый.
