# ТЗ: Тайм-трекер для Тимура

Веб-приложение: засекать рабочее время по категориям и задачам, смотреть статистику, видеть визуальный прогресс. Многопользовательское (Тимур раздаст команде), мобильная вёрстка обязательна — Тимур заходит с телефона.

**Решение Тимура по приоритету (созвон №4, 24:10–26:38):** сначала **«техничка» + база данных, без оформления** — «можно нажать, и оно записывается, всё собирается — я просто буду юзать». Геймификация и красота — вторым этапом.

Работу ведут три агента (установлены в `.claude/agents/`), строго в порядке:
**Агент 1 `backend-supabase` → Агент 2 `frontend-ui` → Агент 3 `qa-verifier`.**
Оба этапа проходят весь конвейер; Этап 1 сдаётся Тимуру не дожидаясь Этапа 2.

---

## Общие вводные

- **Репозиторий:** `e:\time-tracker`, git, ветка `main`.
- **Стек:** Vite + React 18 + TypeScript, Tailwind CSS, Framer Motion (этап 2), supabase-js v2. Основное разрешение **390×844**.
- **База:** Supabase (оплаченный проект). В базе уже есть функция **`tt_category_totals()`** — суммарные секунды по категориям с RLS «каждый видит только своё». Не ломать, опираться.
- **Публичная ссылка:** Cloudflare Pages (`npm run deploy` → `wrangler pages deploy dist`). Ссылку — Тимуру сразу после Этапа 1.
- Тексты интерфейса — русские; без эмодзи (SVG-иконки) и без системных `confirm`/`alert`.

# ЭТАП 1 — Техничка (приоритет, сдать как можно скорее)

Никакого оформления сверх аккуратной мобильной вёрстки. Функциональность по структуре созвона №3:

## Данные (ядро)

- **Категории** (Тимур зовёт их «школы»/«области»): «Саморазвитие», «Школа», «Финансы»… Пользователь создаёт свои.
- **Задачи внутри категории (опционально):** время можно засечь либо на категорию целиком («глобально 5 часов на эту школу»), либо на конкретную задачу («задача по финансам — 2 часа»).
- **Сессии:** старт/стоп, привязка к категории и (опц.) задаче, длительность.

## Функции

1. **Авторизация** — настоящая, простейшая (магик-линк или логин/пароль). Данные доступны с разных устройств (телефон + комп); многопользовательность — у каждого свои категории/задачи/статистика. Anonymous sign-in НЕ подходит.
2. **Таймер:** Старт → идёт (видно прошедшее время, «35 минут прошло») → Стоп. Два режима запуска: (а) на категорию без задачи; (б) на задачу внутри категории.
3. **CRUD категорий и задач.**
4. **Статистика:** разрезы **день / неделя / месяц**; общее время + по категориям + по задачам; сводка по каждой категории (в т.ч. 0, если не занимался); графики.
5. **Простой визуальный прогресс:** прогресс-бары по категориям (план/факт или просто накопленное). Геймификацию (персонаж, предметы, планета) — заложить в архитектуру (пороги и totals уже считаются), но НЕ рисовать сейчас.
6. **Деплой** на Cloudflare Pages, ссылку — Тимуру.

## Критерии приёмки Этапа 1

- С телефона: зайти под своим аккаунтом, стартануть/остановить таймер на категорию и на задачу — сессия появляется в БД и в статистике.
- Второй пользователь не видит чужих данных.
- Таймер переживает перезагрузку страницы (активная сессия восстанавливается из БД).
- Статистика день/неделя/месяц сходится с `tt_category_totals()`.

# ЭТАП 2 — Редизайн и геймификация «Мини-планета»

## Визуальный стиль — строго по референс-фото (папка с референсами)

Не «слоновая кость + изумруд», а **глассморфизм поверх живой зелёной сцены**, как на фото GolfX / ShotScope / стеклянного календаря:

- **Фон экрана — сама сцена:** сочная зелень «вида сверху» (на главном экране — планета), занимает весь экран. Никаких плоских однотонных фонов.
- **Все панели — стекло:** полупрозрачные, `backdrop-blur`, скруглённые (radius 20–28px), тонкая светлая кромка. Два тона стекла: тёмное дымчатое (как нижняя панель GolfX) и светлое матовое (как карточки ShotScope).
- **Акценты:** лаймово-жёлтый (как логотип GOLFX и подчёркивание активной вкладки) + глубокий зелёный. Текст на тёмном стекле — белый, вторичный — приглушённо-серый.
- **Сегмент-контролы — пилюли** (как Weekly/Monthly в календаре и Strikes/Statistics в ShotScope): активный сегмент — белая/чёрная пилюля, скользит пружинно.
- **Метки на сцене** — маленькие белые пилюли с хвостиком (как «156 yd» на поле).
- **Крупные цифры** — тонкая крупная типографика, как «April 21» в календаре: Unbounded; текст — Golos Text (обе с кириллицей).
- Всё нажимаемое пружинит (Framer Motion), экраны въезжают, списки каскадом.

## Навигация

Плавающий стеклянный таб-бар внизу, 5 вкладок с SVG-иконками: **Домой · Таймер · Статистика · Планета · Категории**. Активная вкладка — лаймовое подчёркивание/пилюля, пружинно скользит.

## Планета (главный экран геймификации) — вместо дерева и карты

- **Мини-планета**, которую можно **крутить и двигать пальцем**; у каждой категории — своя зона на планете.
- **Чувачок** строит и расширяет зону по мере наработанных часов; при идущем таймере он работает в зоне активной категории (над головой стеклянный бабл с тикающим временем), без сессии — отдыхает в центре.

### Тематические зоны — у каждой категории свой «бизнес»

Зоны НЕ одинаковые: при создании категории ей назначается **тема** (пользователь выбирает из набора, свободные темы предлагаются по очереди). Каждая тема — свой способ «приносить деньги» и свой набор построек:

| Тема | Развитие снаружи (по часам) | Интерьер (куда проваливаешься) |
|---|---|---|
| **Шахта** | палатка старателя → вход в шахту → вагонетки → блеск алмазов из шахты | подземный разрез: герой копает киркой, алмазы поблёскивают в породе, вагонетка увозит добычу |
| **Корпорация** | вагончик-офис → первое здание → квартал небоскрёбов → золотой логотип на крыше | офис: герой за столом среди этажей, лифт ездит, на табло растут цифры |
| **Космопорт** | ангар → стартовая площадка → ракета в сборке → космолёт стартует | цех сборки: герой крутит гайки у ракеты, искры сварки, обратный отсчёт на табло |
| **Нефтевышка** | буровая палатка → качалка → цистерны → фонтан нефти с золотым отливом | буровая платформа: герой у рычагов, качалка качает, бочки наполняются |
| **Банк** | обменный киоск → здание с колоннами → хранилище → золотой купол | хранилище: герой возит тележки со слитками, дверь-сейф, стопки монет растут |

Набор тем расширяемый (конфиг в `src/lib/themes.ts`); пороги часов едины для всех тем: **1 / 3 / 7 / 15 / 30 / 50** (уровни зоны: Пустырь → Лагерь → Дело → Бизнес → Компания → Империя → Легенда). Черновик — подтвердить у Тимура; хранить в `src/lib/thresholds.ts`.

### Проваливание внутрь зоны

- Тап по зоне (или по достижении порога 7 ч) — камера **ныряет внутрь**: плавный зум-переход с планеты в интерьер темы (см. таблицу).
- В интерьере видно, как **герой работает**: в шахте копает и добывает алмазы, в корпорации сидит среди небоскрёбов, в космопорте собирает ракету. Если таймер этой категории идёт — герой активно работает и бабл с временем тикает; если нет — интерьер «спит» (приглушённый свет, герой отдыхает).
- Наполнение интерьера тоже растёт с часами (больше алмазов в породе, больше этажей, ракета ближе к старту).
- Выход — кнопка-стрелка на стекле или жест pinch-out: камера выныривает обратно на планету.

- Архитектура — расширяемая: в будущем предметы, покупки за «заработанное» (не делать сейчас, но не закладывать препятствий).
- Зона активной категории подсвечена пульсирующей каймой её цвета; при активной сессии планета сама доворачивается к ней.
- Внизу — стеклянная панель: «N зон · всего N ч».

## Экран «Домой»

- Приветствие по времени суток («Доброе утро, Тимур») + дата.
- Если таймер идёт — живая стеклянная пилюля «Сейчас идёт: Финансы · 25:14».
- Крупно — наработано сегодня + топ-3 категории дня.
- Главная кнопка **«Продолжить: {категория} · {задача}»** — повтор последней сессии одним тапом. Рядом «Другое…».
- Мини-карточка «Моя планета» → ведёт на Планету.
- Пустое состояние: «Чистый лист. Один тап — и день пошёл в зачёт».

## Экран «Таймер» — ритуал

- Кольцо прогресса **240px** вокруг цифр (оборот за час), градиент зелёного с лаймом, мягкое пульсирующее свечение — таймер «дышит». Фон — сцена планеты в расфокусе, цифры на стекле.
- Подпись «Идёт 25-я минута. Не отвлекаемся».
- **Стоп — празднование:** стеклянная карточка «+42 мин — зона „Финансы" подросла»; при пересечении порога — что нового построено.

## Экран «Статистика»

- Пилюльный сегмент-контрол **День/Неделя/Месяц**, крупный итог, график со скруглёнными столбцами на стеклянной панели, полосы категорий с процентами (как список метрик ShotScope), наполняются анимацией. Разрез и по задачам внутри категории.

## Экран «Категории»

- Список категорий (цвет, иконка, суммарное время) + задачи внутри; создание/редактирование в стеклянном bottom-sheet. Удаление — архивация с undo-тостом.

## Агент 1 — `backend-supabase`

**Зона:** Supabase + `src/lib/`, `src/api/`. UI не трогает.

1. Scaffold репозитория (Vite + React + TS, tailwind, framer-motion, supabase-js; `.env` в `.gitignore`, `.env.example`; wrangler + `npm run deploy`).
2. Миграции (все таблицы `tt_`, RLS по `auth.uid()`):
   - `tt_categories`: id, user_id, name, color, icon, **theme** (slug темы зоны: mine / corporation / spaceport / oil / bank...), archived, created_at.
   - `tt_tasks`: id, user_id, category_id (FK), name, archived, created_at.
   - `tt_sessions`: id, user_id, category_id (FK), **task_id (FK, nullable)**, started_at, ended_at (null = идёт), duration_seconds, note.
   - `tt_category_totals()` не ломать; при необходимости расширить совместимо. Добавить `tt_task_totals()`, `tt_today_totals()`, `tt_stats(period)`.
3. **Auth:** email магик-линк или логин/пароль (решить по простоте, но НЕ anonymous) — мультиустройство и мультиюзер.
4. API-слой: `getCategories/createCategory/...`, `getTasks/createTask/...`, `startSession(categoryId, taskId?)`, `stopSession`, `getActiveSession`, `getLastSession`, `getCategoryTotals`, `getTaskTotals`, `getTodayTotals`, `getStats(period)`.
5. Одна незакрытая сессия на пользователя (partial unique index); новый старт закрывает старую.
6. После миграций — `get_advisors`, закрыть security-замечания.

## Агент 2 — `frontend-ui`

**Зона:** весь UI, данные только через `src/api/`.
